# ABC Sales Dashboard

## Project Overview
This project involves the development of an interactive sales dashboard using Microsoft Excel to analyse and monitor business performance.

The dashboard provides a consolidated view of key business metrics, enabling users to explore sales performance, profitability, product trends, customer demographics and returns across different periods and store branches.

## Project Objectives
- Monitor overall sales and business performance.
- Analyse revenue, expenses and profitability.
- Evaluate product and brand performance.
- Examine sales trends across different years and months.
- Analyse customer demographics and purchasing patterns.
- Track product returns and their impact on business performance.
- Provide an interactive reporting interface to support business decision-making.

## Key Performance Indicators (KPIs)
- Total Revenue
- Total Expenses
- Total Profit
- Profit Margin
- Product Returns

## Tools and Techniques
- Microsoft Excel
- Power Query
- PivotTables and PivotCharts
- Excel Formulas and Functions
- Data Cleaning and Transformation
- Interactive Dashboard Development
- Data Visualisation

## Dashboard Features
- Interactive filters for exploring business performance.
- KPI cards for monitoring key metrics.
- Visual analysis of sales and profitability.
- Product and brand performance comparisons.
- Customer demographic analysis.
- Trend analysis across different reporting periods.

## Project Outcome
The project demonstrates how Microsoft Excel can be used to transform raw business data into an interactive reporting solution. It provides a structured approach to monitoring business performance, identifying trends and presenting relevant insights for informed decision-making.

## Conclusion
This project strengthened my practical skills in Excel-based data analysis, dashboard development and business performance reporting, while demonstrating the application of data analytics techniques to real-world business scenarios.
