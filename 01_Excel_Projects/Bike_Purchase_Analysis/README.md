## Project Overview
This project explores customer purchasing behaviour in the bicycle market, with the aim of identifying factors that influence customers' decisions to purchase bicycles.

The analysis examines customer demographics and purchasing patterns to uncover relationships between customer characteristics and bike purchase decisions.

## Project Objectives
- Analyse customer purchasing behaviour.
- Examine the relationship between age and bike purchase decisions.
- Explore purchasing patterns across gender and income groups.
- Investigate how factors such as occupation, commute distance and marital status relate to purchasing decisions.
- Identify customer segments with different purchasing patterns.

## Tools Used
- Microsoft Excel
- Data Cleaning and Transformation
- PivotTables and PivotCharts
- Excel Formulas
- Data Visualisation
- Interactive Dashboard Development

## Key Areas of Analysis
- Customer demographics.
- Income distribution.
- Age-group purchasing patterns.
- Commute distance.
- Bike purchase frequency across customer segments.

## Project Outcome
The project demonstrates how customer data can be analysed to identify purchasing patterns and generate insights that can support customer segmentation, marketing strategies and business decision-making.

## Conclusion
This project strengthened my practical experience in using Microsoft Excel to explore customer behaviour, analyse demographic data and communicate findings through data visualisation.
