## Project Overview
This project examines global gas flaring trends across 107 countries over a 14-year period (2012–2025).

The analysis explores changes in flaring volumes, identifies major contributing countries and highlights global trends in gas flaring.

## Tools Used
- Microsoft Excel
- Power Query
- PivotTables
- PivotCharts
- Data Cleaning and Transformation
- Data Visualisation

## Project Objectives
- Examine historical global gas flaring trends.
- Identify countries with the highest gas flaring volumes.
- Analyse changes in flaring volumes over time.
- Highlight countries that have achieved zero gas flaring.

## Key Findings
The analysis identified significant variations in gas flaring volumes across countries, with a small number of major contributors accounting for a substantial share of global flaring.
