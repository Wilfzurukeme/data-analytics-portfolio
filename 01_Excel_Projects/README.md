# Excel Data Analytics Projects

This folder contains a collection of data analytics projects developed using Microsoft Excel. These projects demonstrate my ability to clean, transform, analyse and visualise data to uncover meaningful insights, identify trends and support data-driven decision-making.

## Projects Included

### 1. Global Gas Flaring Analysis (2012–2025)
An analysis of global gas flaring trends across 107 countries, examining historical patterns, major contributors and changes in flaring volumes over 14 years.

### 2. 2022 Methane Emissions Analysis
An analysis of methane emissions data, exploring emission patterns and their implications using Global Warming Potential (GWP) metrics.

### 3. ABC Sales Dashboard
An interactive sales dashboard designed to monitor business performance across different years, months and store branches. The dashboard provides insights into revenue, expenses, profit, profit margins, product performance, returns and customer demographics.

### 4. Bike Purchase Analysis
An analysis of bike purchase data aimed at exploring customer purchasing patterns and identifying trends that can support better understanding of customer behaviour and purchasing decisions.

## Tools and Techniques
- Microsoft Excel
- Power Query
- PivotTables and PivotCharts
- Data Cleaning and Transformation
- Data Analysis and Visualisation
- Interactive Dashboard Development
- Trend Analysis and Reporting

## Objective

These projects reflect my interest in applying data analytics to real-world business and energy industry problems. They also demonstrate my continuous development in using data to generate actionable insights and support informed decision-making.
