## Project Overview

This project involves the development of an interactive business intelligence dashboard using Microsoft Power BI to analyse sales performance and key operational metrics.

The dashboard provides a comprehensive view of business performance, covering revenue, costs, profitability, branch performance, product analysis, customer insights and product returns.

The objective is to transform business data into meaningful insights that support performance monitoring, identify trends and facilitate informed decision-making.

## Project Objectives

- Monitor overall revenue, costs and profitability.
- Analyse sales and profit trends across different periods.
- Evaluate branch performance against established sales targets.
- Identify products contributing significantly to revenue and profitability.
- Examine customer characteristics and purchasing patterns.
- Analyse product returns and their financial implications.
- Track business performance using interactive reporting features.

## Dashboard Pages and Analysis

### 1. Executive Summary
Provides an overview of key business performance indicators, including revenue, cost, profit and profit margin.

### 2. Sales Analysis
Examines sales performance over time, including revenue, costs, profit, order volumes and month-over-month comparisons.

### 3. Branch Analysis
Evaluates individual branch performance, comparing actual sales and profitability against sales targets.

### 4. Return Analysis
Investigates product returns, return-related costs, lost sales and the reasons behind returned products.

### 5. Product Analysis
Explores product-level performance through revenue, profit, quantity sold, orders and available inventory.

### 6. Customer Analysis
Examines customer characteristics, including gender and marital status, alongside revenue-related analysis.

## Key Features

- Interactive KPI cards.
- Dynamic filters and slicers.
- Month-over-Month performance analysis.
- Branch sales target monitoring.
- Product and customer analysis.
- Return and financial impact analysis.
- Interactive page navigation.

## Project Outcome

The project demonstrates the application of Power BI in developing an interactive business intelligence solution for monitoring sales performance and analysing different aspects of business operations.

It showcases practical skills in data modelling, analytical calculations, time-based analysis, report design and data storytelling.

## Conclusion

This project highlights how business intelligence tools can transform business data into actionable insights, enabling organisations to monitor performance, identify operational trends and make informed decisions.
