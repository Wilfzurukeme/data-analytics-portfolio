# Electronics Retailer Analysis – Power BI

## Project Overview

This project involves the development of an interactive business intelligence solution for an electronics retail business using Microsoft Power BI.

The objective was to analyse sales transactions, product performance, customer demographics, profitability and delivery operations to provide insights into business performance and customer purchasing behaviour.

The project was completed as a group capstone project under the GIZ Tech4Youth training programme, with our team operating under the name MAYBACH.

## Project Objectives

- Evaluate overall sales and profitability performance.
- Analyse product performance across brands, categories and subcategories.
- Examine customer demographics and purchasing patterns.
- Identify monthly and yearly sales trends.
- Analyse customer order and delivery patterns.
- Evaluate the impact of currency exchange rates on sales reporting.
- Develop an interactive dashboard to support business intelligence and decision-making.

## Tools and Technologies

- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Data Modelling
- Microsoft Excel
- Data Cleaning and Transformation
- Data Visualisation

## Data Preparation and Modelling

The project involved preparing and transforming multiple datasets, including sales transactions, customer information, product details, currency information and exchange rates.

Key activities included:
- Cleaning and transforming raw datasets using Power Query.
- Correcting data types and handling missing values.
- Creating calculated columns and analytical measures using DAX.
- Establishing relationships between different data tables.
- Developing a date table for time-based analysis.
- Implementing currency conversion logic for consistent sales reporting.

## Key Areas of Analysis

1. **Sales Performance:** Monitoring revenue and sales trends across different periods.
2. **Product Analysis:** Evaluating product performance across brands, categories and subcategories.
3. **Customer Demographics:** Exploring customer characteristics and purchasing patterns.
4. **Profitability Analysis:** Examining revenue, costs and profit performance.
5. **Time Intelligence:** Analysing monthly and yearly performance, including Month-over-Month and Year-over-Year comparisons.
6. **Delivery Analysis:** Examining order fulfilment and delivery timelines.

## Dashboard Features

- Interactive KPI cards.
- Dynamic slicers and filters.
- Monthly and yearly performance analysis.
- Product and brand drill-down analysis.
- Customer demographic visualisations.
- Time intelligence calculations using DAX.
- Interactive charts and report navigation.

## Project Outcome

The project demonstrates the application of Power BI in transforming raw retail transaction data into an interactive business intelligence solution.

It provided practical experience in data preparation, relational data modelling, DAX calculations, time intelligence and dashboard development.
