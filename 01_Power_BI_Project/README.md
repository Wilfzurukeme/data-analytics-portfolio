# Power BI Data Analytics Projects

## Overview
This folder contains a collection of data analytics and business intelligence projects developed using Microsoft Power BI.

The projects demonstrate my ability to transform raw datasets into meaningful insights through data cleaning, data modelling, DAX calculations, interactive visualisations and dashboard development.

My approach focuses on translating business data into actionable insights that support informed decision-making and performance monitoring.

## Tools and Technologies
- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Data Modelling
- Data Transformation and Cleaning
- Interactive Dashboards and Reports
- Data Visualisation

## Core Competencies Demonstrated
- Data extraction, cleaning and transformation.
- Designing and managing relational data models.
- Creating calculated columns and measures using DAX.
- Developing interactive dashboards and reports.
- Implementing drill-downs, slicers and filters.
- Analysing business performance and identifying trends.
- Communicating insights through data visualisation.
